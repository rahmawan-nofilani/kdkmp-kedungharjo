# KDKMP Kedungharjo

Production rebuild for Koperasi Desa Merah Putih Kedungharjo.

## Phase 0

Foundation only. No real member or financial data may be used yet.

Target platform:
- Web / desktop teller
- Mobile PWA
- Android APK via Capacitor
- Cloudflare deployment
- Supabase Auth
- Zero-recurring-cost target during early operation

## Safety

Do not commit passwords, OTPs, signing keys, Supabase secret/service-role keys, Cloudflare API tokens, or real member financial data.
